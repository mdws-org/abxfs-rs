What this page does

A project's files are checked against its root wherever they are shown. Which root is the project's current one is a separate question, and this page answers it two ways and compares the answers.

By proof: starting from a block built into this viewer, it follows Ethereum's sync committee to a recent finalized block, checking each signature, and reads the project's root out of that block's state with a Merkle proof. No server is believed along the way. By agreement: it asks several public endpoints for the root, at that same block and at the newest block.

Finality runs about a quarter of an hour behind. A version published since then cannot be proved yet, and is reported as such.

This page is on its own address, which a project's scripts cannot change. A project's page can show any words it likes, including these; only the page whose address begins with check. is this one. The proof rests on two things: the starting block built into this viewer, and at least two thirds of each sync committee since then being honest. Committee members are not penalised for signing a false block.
